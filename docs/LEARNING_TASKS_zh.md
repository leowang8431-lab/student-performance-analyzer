# 你的第一批实际贡献

先运行，再读代码，最后小步修改并测试。不要把尚未完成的功能写进简历。

## 先解释三个函数

load_data() 的输入和输出是什么？validate_data() 为什么遇到缺失数据要停止？
summarize() 中 ddof=1 为什么对应样本方差？
手算 50、60、70 的均值和样本标准差，再对照测试。结果应为均值 60、样本
方差 100、样本标准差 10。

## 第一个独立功能：添加分数范围

给 summarize() 添加 score_range（最高分减最低分），在报告中显示它，再写
测试证明 50、60、70 的分数范围等于 20。不要删除已有测试。
建议提交说明：`feat: add exam score range with a regression test`。

## 第二个功能：缺失数据报告

先按列统计缺失条数，再提示用户。默认仍然不删除记录、不填补数据；任何
改变样本的处理都需要解释原因。新增测试，并确认原始数据没有被修改。

## 第三个任务：用英文解释你的发现与限制

解释为何 Pearson 相关不能回答“哪个因素的因果影响最大”。写你自己理解的
Interpretation 段落。模拟数据不能作为现实群体规律的证据。

但先检查是否已存在同名仓库，不要覆盖已有项目。无须现在购买服务器或 API。
